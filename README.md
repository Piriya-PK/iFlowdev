# IFLOWDEV Static Site

This site is split into three main files so it is easier to maintain:

- `index.html` - page content and section markup
- `assets/styles.css` - colors, layout, responsive rules, and animations
- `assets/app.js` - page switching, mobile menu, language toggle, and reveal animation

For most content edits, start in `index.html`.
For visual changes, start in `assets/styles.css`.
For navigation or language behavior, start in `assets/app.js`.
